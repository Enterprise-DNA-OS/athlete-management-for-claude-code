---
description: The Monday review, written from three commands: the programme in numbers, what needs a decision, and the training load picture.
---

Run these three and write the review from what they return. Nothing they do not support goes in.

```
npm run athletes -- stats
npm run athletes -- attention
npm run athletes -- loads
```

Then, no more than a page:

1. **The week in one line.** Athletes available, modified and out; wellness forms in; sessions and total load.
2. **Rules.** Every breach with the athlete and the fix. These lead because they are the programme's duty of care.
3. **Availability.** Who is back, who is out and for how long, concussions and their earliest dates.
4. **Load.** Who spiked, who dropped, and whether the squad's week matched the plan.
5. **Wellness and testing.** Patterns across the week, not single bad mornings.
6. **Five things to do this week**, from the attention list, with why each made it.
7. **One thing to decide.** The single item that needs the head of performance or the doctor.

`npm run view -- week`, `npm run view -- loads` and `npm run view -- injuries` render the same numbers as printable pages.
